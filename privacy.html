Политика конфиденциальности

Действует с 24 ноября 2026

Коротко

Страница статическая: нет регистрации, нет форм, нет счётчиков аналитики и рекламных пикселей. Адреса кошельков и суммы здесь не вводятся и не хранятся. Всё, что остаётся после визита, — технические записи хостинга.

Какие данные обрабатываются

  • Технические логи GitHub Pages. IP-адрес, дата и время запроса, адрес страницы, тип браузера. Платформа ведёт их, чтобы отдать файлы, кэшировать их и защищаться от перегрузок.
  • Cookie. Собственных cookie страница не ставит: нет баннера согласия и нет идентификаторов. Cookie может появляться на стороне хостинга — по его правилам.
  • Локальное хранилище. Сейчас не используется; если понадобится для настройки отображения, здесь появится отдельный пункт.
  • Внешние переходы. После нажатия кнопки вы попадаете на другой домен, и дальше действует политика уже его владельца.
  • Письма. Если пишете на почту, хранятся адрес и текст переписки — только для ответа.

Чего здесь нет

  • Нет скриптов аналитики, которые строят профиль между сайтами.
  • Нет рекламных пикселей и ретаргетинга на этой странице.
  • Нет форм с персональными данными, кроме почты в письме.
  • Нет передачи данных третьим лицам, кроме хостинга.

Партнёрские ссылки

Кнопки ведут на сервис по партнёрской ссылке: к адресу может добавляться параметр перехода. Этот параметр видит сервис, а не сторонние сети. На цене обмена для пользователя партнёрство не отражается.

Правовые основания

Обработка минимальна и основана на законном интересе: обеспечить работу страницы и её защиту. Для писем основание — ваше обращение.

Сроки

Логи хостинга — по правилам платформы, обычно до 30 дней. Письма храним, пока идёт переписка, и до года после.

Ваши действия

Cookie и локальное хранилище можно очистить в настройках браузера — страница продолжит работать. Отписаться от переписки можно любым письмом, тогда данные удалим, если нет незакрытого вопроса.

Сторонние сервисы

Хостинг — GitHub Pages. Переход по кнопке ведёт на зеркало сервиса. У каждого свои правила обработки, с ними стоит ознакомиться отдельно.

Связь

Вопросы по данным: support@seedscan.top. Отвечаем 1–2 рабочих дня.
